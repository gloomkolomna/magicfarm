# План реализации по principe.md

> Анализ расхождений между механиками из `docs/principe.md`, текущими правилами (`docs/Правила.md`), и реализованным кодом.
> Дата: 2026-08-11. **Актуализировано: 2026-08-11 (вечер).**

---

## 1. Общая оценка

Текущий код покрывает ~90% механик из `principe.md`. Реализованы: модель грядок (Plot с qty 1–20), розыгрыш карт кристаллов по уровню растения, карты сокровищ, фото до/после для всех действий (StitchReport с context_type/context_id), сбор урожая → склад растений, переработка растений в товары (craft с сессиями), нормы переработки по уровням, библиотека рецептов с изучением, каталог растений/товаров/животных/питомцев/производств в админке, нормы кристаллов (пресеты 1–8 + пользовательские), скотный двор (загоны, кубик, продукция, цена = opening_order × 5), система уровней с разблокировками, достижения (9 типов условий), касса/продажа излишков, карты по типам шатров (3/4/5), питомцы-помощники с бонусами, зельеварение (котлы, 15 рецептов, активация), медиа (GameMedia: видео колоды, кубика, картинки граней).

## 2. Что реализовано

### 2.1. Количество растений на грядке ✅
- `POST /fields/{id}/cells/{col}/{row}/plant` принимает `qty: int = 1` (1–20).
- Норма = crystal_norm × qty.
- Реализовано в `routes/fields.py:110,171,189,193`.

### 2.2. Розыгрыш карт по уровню растения + сокровища ✅
- `CARD_DRAW_RULES` в `models.py:14-21`:
  - plant_1: 1 карта, без сокровищ.
  - plant_2: 2 карты, сокровища возможны.
  - plant_3: 3 карты, сокровища возможны.
- 15 обычных карт + 3 сокровища в таблице `crystal_cards`.
- Используется в `plant_on_cell` и `start_tent_build`.

### 2.3. Фото «до и после» для всех действий ✅
- `StitchReport` имеет `photo_before_url`, `photo_after_url`, `context_type`, `context_id`.
- Типы контекста: plant_grow, recipe_study, production, animal_build, animal_produce, tent_build, pet_settle.
- Реализовано в `routes/stitches.py:112-163`, модель `models.py:110-114`.

### 2.4. Сбор урожая → склад растений ✅
- `harvest_cell` добавляет растения в `Inventory` (plant_id).
- `Inventory` хранит и растения, и товары (plant_id / product_id).
- Реализовано в `routes/fields.py:261-268`.

### 2.5. Переработка растений в товары (craft) ✅
- `craft_product`: выбор растения со склада → проверка рецепта → норма = get_production_norm(lvl) × qty → CraftSession → stitch_report → списание растений + зачисление товара.
- Реализовано в `routes/farm.py:200-266`, `routes/stitches.py:42-62`.

### 2.6. Настройка норм переработки по уровням ✅
- Настройки: `production_norm_lvl1`, `production_norm_lvl2`, `production_norm_lvl3`.
- Функция `get_production_norm(db, level)` в `routes/settings.py:233`.

### 2.7. Библиотека / изучение рецептов ✅
- Каталог рецептов с иконками растений и товаров.
- 3 нормы изучения: `study_norm_lvl1`, `study_norm_lvl2`, `study_norm_lvl3` (игрок настраивает в онбординге).
- Изучение: норма → фото до/после → рецепт открыт.
- Реализовано в `routes/library.py`, `routes/stitches.py:64-72`.

### 2.8. Скотный двор / животные ✅
- 8 волшебных животных, `BarnyardSlot` (user_id, animal_id, status, accumulated, required).
- Установка: install → building (5 карт) → invest крестиками → ready.
- Продукция: бросок кубика d6 → норма = animal_production_norm × die → фото → продукция.
- Цена продукции: `opening_order × 5` (первое животное = 5 монет, восьмое = 40).
- Настройки: `animal_build_norm`, `animal_production_norm`.
- Реализовано в `routes/barnyard.py`, модель `models.py:465-479`.

### 2.9. Система уровней и прогрессии ✅
- 16 уровней (0→16). `LevelGate`: level, coins_required, plots_required, unlock_type, image_url.
- Админ задаёт уровни с разблокировками и картинками в админке.
- `check_level_up` проверяет монеты + грядки, повышает уровень, применяет разблокировку.
- Разблокировки влияют на игру:
  - Животноводство +N → unlocked_barnyard += N → автосоздание загонов.
  - Питомец-помощник +1 → unlocked_pets += 1 → лимит питомцев.
  - Сад N уровня → unlocked_garden_level = N → доступ к orchard-растениям.
  - Грядка N уровня → unlocked_plot_level = N → доступ к garden_beds-растениям.
- `POST /api/levels/advance` для ручного перехода.
- Реализовано в `services/leveling.py`, `routes/levels.py`, `routes/fields.py:160-169`,
  `routes/barnyard.py:43-56`, `routes/pets.py:59-64`.

### 2.10. Достижения ✅
- 9 типов условий: first_plant, plots_count, first_order, coins_reached, animals_count, pets_count, potions_count, tents_count, level_reached.
- Модели: `Achievement` + `UserAchievement`.
- `check_and_award` — хук при ключевых действиях игрока.
- `GET /api/achievements` — с флагом earned.
- Реализовано в `services/achievements.py`, `routes/achievements.py`.

### 2.11. Касса / продажа излишков ✅
- `POST /api/farm/sell-surplus`: item_kind (plant/product), item_id, qty.
- Цена = ½ цены заказа (`sale_price_ratio`, по умолчанию 0.5).
- Списание со склада, зачисление монет.
- Реализовано в `routes/farm.py:323-372`.

### 2.12. Карты сокровищ ✅
- 3 карты сокровищ в таблице `crystal_cards` (color × 1 count, is_treasure=1).
- `_treasure_norm()` рассчитывает норму сокровища.
- Реализовано в `services/card_draw.py:44-50`.

### 2.13. Разное количество карт для шатров ✅
- `CARD_DRAW_RULES` в `models.py:14-21`:
  - tent_sewing: 3 карты.
  - tent_workshop: 4 карты.
  - tent_alchemy: 5 карт.
- Используется в `start_tent_build`.

### 2.14. Видео/анимации ✅
- Модель `GameMedia` (code, kind: image/video, url).
- Поддерживаемые коды: card_shuffle, dice_roll, dice_face_1–6.
- `GET /api/game-media` — публичный список.
- `GET /api/game-media/{code}` — по коду.
- Реализовано в `routes/game_media.py`.

### 2.15. Уникальность растения на грядку ✅
- Проверка при посадке: `Plot.user_id == user.vk_id AND Plot.plant_id == req.plant_id AND Plot.cell_id.isnot(None)` → 409.
- Реализовано в `routes/fields.py:177-184`.

### 2.16. Сады ✅
- Категория `orchard` у растений и полей.
- Доступность садов по `unlocked_garden_level` игрока (через систему уровней).
- `min_level` на полях как дополнительный гейт.
- Реализовано в `routes/fields.py:160-169`, `models.py:124`.

### 2.17. Питомцы-помощники ✅
- 5 питомцев (Лис, Кот, Ворон, Дракон, Игуана) с бонусами.
- Получение: вытянуть 10 карт → норма → фотоотчёт.
- Бонусы: +1 урожай сада/грядки, +5 монет к заказу, +1 товар при крафте, +1 продукция животного.
- Лимит: `unlocked_pets` (растёт через систему уровней).
- Реализовано в `routes/pets.py`, `services/pet_bonuses.py`.

### 2.18. Формула цены животного ✅
- Цена продукции = `opening_order × 5`.
- `opening_order` = количество уже заселённых загонов + 1.
- Реализовано в `routes/barnyard.py:97-100,193`.

### 2.19. Зельеварение (котлы, рецепты, эффекты) ✅
- 3 котла (олово/серебро/золото на 4/5/6 ингредиентов).
- 15 рецептов (6 зелёных, 5 синих, 4 фиолетовых).
- Ингредиенты со склада, 1 тайл на слот, нельзя забрать до завершения.
- Эффект на 1 раунд (активация зелья).
- Реализовано в `routes/potions.py`, модели `models.py:507-558`.

### 2.20. Нормы изображений кристаллов ✅
- Админ загружает картинки кристаллов (зелёный/синий/фиолетовый × 1–5).
- `CrystalCardImage` модель, `GET /api/crystal-card-images`.
- Реализовано в `routes/settings.py` (crystal_card_images роутер).

### 2.21. Стадии растений (молодое/созревшее) ✅
- `Plant.image_young_url`, `Plant.image_grown_url`.
- `POST /api/admin/plants/{id}/stage-image` (young/grown).
- Реализовано в `routes/admin_catalog.py`, `routes/plants.py`.

### 2.22. Тенты/производства на полях ✅
- 3 типа: alchemy (стол зельеварения), sewing (шатёр портнихи), workshop (мастерская).
- Установка через поле с клетками: `start_tent_build` → `invest` → готов.
- `ProductionTemplate` с картинками и нормами.
- Реализовано в `routes/fields.py` (tent_build), `routes/admin_fields.py` (tents CRUD).

### 2.23. Заказы с авто-генерацией ✅
- `OrderTemplate` — шаблоны заказов (plant_id, product_id, qty, reward_coins, customer).
- Авто-создание заказов при посадке растения или установке загона.
- Глобальные заказы (user_id=null) + персональные.
- Реализовано в `routes/orders.py`, `routes/admin_orders.py`.

## 4. Что нового в этой сессии (2026-08-11)

### 4.1. Редизайн системы уровней (маршрутов)
- **Было:** 4 варианта маршрутного листа, игрок выбирал вариант (1–4) и не мог сменить.
- **Стало:** единый маршрут без вариантов. Админ заполняет 16 уровней с параметрами.
- Убран `User.route_variant`, убран `LevelGate.variant`.
- Добавлен `LevelGate.unlock_type` — выпадающий список: Животноводство +1/+2, Питомец-помощник +1, Сад 1/2/3 уровня, Грядка 2/3 уровня.
- Добавлен `LevelGate.image_url` — картинка-иллюстрация уровня (админ загружает).
- Админка: новый UI с выпадающим списком и загрузкой картинки.
- Фронтенд: убран выбор варианта на главной (Fields.tsx).

### 4.2. Разблокировки влияют на игру
- `User.unlocked_barnyard` — автосоздание загонов в `GET /api/animals/pens`.
- `User.unlocked_pets` — лимит питомцев в `POST /api/pets/settle`.
- `User.unlocked_plot_level` — блокировка garden_beds-растений выше уровня.
- `User.unlocked_garden_level` — блокировка orchard-растений выше уровня.
- `check_level_up` применяет разблокировки при переходе на уровень.
- `/api/me` возвращает все 4 поля разблокировок.

### 4.3. Исправлен баг в check_level_up
- Перезапрос юзера из той же сессии, что и `db` — гарантирует сохранение изменений.

## 9. Решения по неясным моментам (согласовано с автором 2026-08-11)

1. **Фото до/после** — ✅ **Для всего.** Каждое действие требует 2 фото: до и после.
   - `StitchReport` имеет `photo_before_url` + `photo_after_url` + `context_type` + `context_id`.

2. **Склад** — ✅ **Общий склад с категориями.** Inventory хранит и растения (`plant_id`), и товары (`product_id`).

3. **Грядки vs Сады** — ✅ **Одна механика.** Сады — та же посадка, другая категория (`orchard`). Доступность — через `unlocked_garden_level`.

4. **Заказы** — ✅ **Авто-генерация из шаблонов.** OrderTemplate → авто-создание OrderReq при посадке/установке загона.

5. **Касса** — ✅ **Кнопка продажи.** `POST /api/farm/sell-surplus` — продажа излишков за ½ цены.

6. **Видео** — ✅ **GameMedia.** Админ загружает видео колоды, кубика, картинки граней.

7. **Зельеварение** — ✅ **Полностью.** Котлы, 15 рецептов, слоты, ингредиенты, активация, бонусы.

8. **Уровни** — ✅ **Единый маршрут.** Без вариантов. Админ задаёт levels 1–16 с монетами, грядками, типом разблокировки и картинкой. Разблокировки влияют на игру (загоны, питомцы, сады, грядки).
