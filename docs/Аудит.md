# Аудит реализации по Правилам игры «Ферма»

> Сопоставление `docs/Правила.md` с текущей кодовой базой.
> Дата: 2026-08-10

---

## 1. Сделано и соответствует правилам

### 1.1. Нормы кристаллов (раздел 4)
- 8 предустановленных вариантов (`VARIANT_TABLES`) — **полное совпадение** с таблицами слайдов 21–22.
- Возможность задать персональные нормы игрока (`UserCrystalNorm`) — аналог «шпаргалки».
- Приоритет: персональная норма → админский стандарт → пресет 1.
- Функция `crystal_norm()` для расчёта нормы по цвету и количеству кристаллов.

### 1.2. Игровое поле (раздел 11)
- Сетка клеток с координатами `(col, row)`.
- Типы клеток: `empty`, `bed` (грядка), `pet` (питомец), `barnyard` (скотный двор), `tent` (шатёр).
- Фоновая карта (изображение), настраиваемый цвет сетки.
- Админка: создание/удаление полей, настройка клеток, привязка растений, размещение шатров.
- Игрок: посадка на клетку, сбор урожая, строительство шатров.

### 1.3. Инвентарь / Склад (раздел 6)
- Модель `Inventory`: `user_id + product_id + qty`.
- Пополнение через крафт на производстве.
- Расходование при выполнении заказов.
- Страница просмотра (`GET /api/farm/inventory`).

### 1.4. Производства (раздел 5) — базовая механика
- Три типа (`alchemy`, `sewing`, `workshop`) + возможность добавлять новые через `ProductionTemplate`.
- Каждое производство устанавливается **один раз** (unique constraint `user_id + kind`).
- Строительство через вложение крестиков с нормой по кристаллам.
- Крафт товара: крестики → инвентарь.

### 1.5. NPC-заказы (раздел 12) — базовая генерация
- 5 NPC-заказчиков (Ученица Холли, Русалка Оресия, Маг Мерлин, Травница Морган, Алхимик Зелье).
- Генерация заказа: игрок выбирает товар → случайный заказчик, награда = `qty × reward_per_unit`.
- Выполнение: списание из инвентаря, начисление монет.
- Админские глобальные заказы (видны всем игрокам).

## 2. Сделано, но не соответствует правилам (или упрощено)

### 2.1. Вышивка / крестики (раздел 3.4, шаг 3)
| Правила | Реализация | Проблема |
|---------|-----------|----------|
| Норма определяется **случайным вытягиванием карт кристаллов** | Игрок вручную вводит число крестиков в фото-отчёте | Нет механики случайных кристаллов при вышивке |
| Жёлтый кристалл = количество вытягиваемых карт | Не реализован | Нет жёлтого кристалла |
| Бонусные карты сокровищ (3 шт.) | Не реализованы | — |
| Вышивка — физический процесс, self-report | Добавлена модерация фото (admin accept/reject) + авто-зачёт (`auto_credit`) | Не предусмотрено правилами, но полезно для цифровой версии |

**Нужно:** либо реализовать розыгрыш кристаллов при отправке отчёта, либо признать ручной ввод осознанным упрощением.

### 2.2. Посадка растений (раздел 3)
| Правила | Реализация | Проблема |
|---------|-----------|----------|
| Открытие конверта с карточкой растения | Нет конвертов | Конверты как механика отсутствуют |
| Бонусы растений (текст/картинка) снижают норму | Поля `bonus_text` / `bonus_kind` есть, но **не влияют на геймплей** | Бонусы не применяются |
| Растения сажаются «грядками» (например, 7 штук) | `qty` в `Plot`, но посадка на поле — всегда `qty=1` на клетку | Нет посадки нескольких растений на одну клетку |
| Уровни грядок 1/2/3 открываются по этапам | Поле `level` есть, гейтинга нет | Игрок может сажать растения любого уровня |

**Нужно:** реализовать бонусы (снижение нормы), добавить гейтинг по уровню.

### 2.3. Производства и крафт (раздел 5)
| Правила | Реализация | Проблема |
|---------|-----------|----------|
| Норма товара = `норма_кристалла × звёздочки × количество` | Звёздочки (`stars`) хранятся, но **не участвуют в расчёте** | Крафт использует фиксированный `required` |
| Изучение рецепта — отдельный шаг с нормой | Крафт доступен сразу после установки шатра | Нет шага «изучение рецепта» |
| Бонусы на карте производства | Не реализованы | — |

**Нужно:** использовать звёздочки в формуле нормы крафта; добавить изучение рецепта.

### 2.4. Продажа и монеты (раздел 6)
| Правила | Реализация | Проблема |
|---------|-----------|----------|
| Монеты начисляются за **каждое действие**: выращивание, установку шатра, производство | Монеты начисляются **только** за выполнение заказов | Нет прямых наград за действия |
| Касса — отдельный конверт, устанавливается один раз | Не реализована | Нет кассы |
| Продажа излишков за ½ цены | Не реализована | — |
| Банковские чеки в дневнике | Не реализованы | — |

**Нужно:** добавить начисление монет за посадку/постройку/крафт; кассу.

### 2.5. Заказы (раздел 12)
| Правила | Реализация | Проблема |
|---------|-----------|----------|
| Заказы приходят из **физических карточек** (привязаны к конвертам) | Генерируются игроком по запросу (`POST /generate`) | Нет фиксированных заказов из конвертов |
| Первый заказ определяет количество растений | Не реализовано | — |
| Заказы зелий (15 доп. карт) | Не реализованы | — |

**Нужно:** либо оставить генерацию как осознанное упрощение, либо добавить фиксированные заказы.

## 3. Не сделано (только модель/заглушка)

### 3.1. Раунды, уровни, маршрутный лист (раздел 7)
- Поле `User.round` существует, но **не изменяется и не влияет на игру**.
- Нет проверки накопления монет для перехода на новый уровень.
- Нет гейтинга контента по раунду (грядки 2–3 уровня, сады, питомцы, животноводство).
- Маршрутный лист (варианты 1–4) полностью отсутствует.

### 3.2. Питомцы (раздел 8)
- Модель `Pet` есть (+ CRUD в админке).
- **Нет игровой механики:**
  - Игрок не может получить питомца.
  - Нет нормы получения (10 карт кристаллов).
  - Бонусы питомцев не применяются (лис +1 дерево, кот +1 грядка, и т.д.).

### 3.3. Животноводство (раздел 9)
- Модель `Animal` есть (+ CRUD в админке).
- **Нет игровой механики:**
  - Игрок не может открыть/купить животное.
  - Нет формулы цены `(номер открытия) × 5`.
  - Нет продукции животноводства.
  - Нет продажи ×2 за 3 заказа.

### 3.4. Сады (раздел 10)
- Категория `orchard` у растений существует, но **сады не выделены как отдельная механика**.
- Нет гейтинга открытия садов по уровням.
- Нет декора сада.

### 3.5. Зельеварение (раздел 13)
- Только тип производства `alchemy` = «Стол зельеварения».
- **Полностью отсутствует:**
  - Котлы (олово 4 / серебро 5 / золото 6).
  - 15 рецептов зелий.
  - Флакончики, страницы для записей.
  - Механика сбора ингредиентов в котёл.
  - Эффекты зелий (действуют 1 раунд).
  - Монеты за приготовление зелий.
  - Заказы на зелья.

### 3.6. Режимы игры (раздел 12)
- Один универсальный режим. Нет разделения на «Карьера», «Заказы», «Творчество».

### 3.7. Дневник, наклейки, декор, чеки
- Полностью отсутствуют в цифровой версии (в правилах — физические элементы).

### 3.8. Конверты и скретч-наклейки
- Механика конвертов (открытие, наклейки, скретч-слой) не реализована.

## 4. Приоритеты (рекомендация)

### 🔴 Критичные расхождения (ломают игровой цикл)
1. **Нет начисления монет за выращивание, установку шатров и производство** — монеты только за заказы. В правилах каждое действие приносит монеты.
2. **Раунды/уровни не работают** — поле `round` есть, но не меняется; нет маршрутного листа; нет гейтинга.

### 🟡 Значимые расхождения (искажают механику)
3. **Звёздочки не участвуют в расчёте нормы крафта** — формула упрощена до фиксированного `required`.
4. **Бонусы растений/производств не применяются** — хранятся, но не влияют на нормы.
5. **Вышивка — ручной ввод вместо случайных кристаллов** — фото+число вместо розыгрыша.

### 🟢 Желательные, но не блокирующие
6. **Питомцы, животноводство, сады** — только каталог, без геймплея.
7. **Зельеварение** — полностью отсутствует как дополнение.
8. **Касса** — отсутствует (продажа излишков, чеки).
9. **Дневник, наклейки, конверты** — физические элементы без цифрового аналога.
